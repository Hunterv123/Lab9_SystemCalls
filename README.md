# Lab9_SystemCalls
CPE2600 Lab 9 System Calls
Author: Hunter Vassar

## Part 1 info.c

 - Looks into information maintenance system calls, uses a list of system calls and builds a small program.

## Part 2 pinfo.c

 - Builds a simple program using system calls available for retrieving information about processes in the system.

## Part 3 pmod.c

 - Uses the nice and system call to lower the priority of a process then delay the program using nanosleep.

## Part 4 finfo.

 - Builds a program using file management system calls that displays basic info about a file path provided by the user.
